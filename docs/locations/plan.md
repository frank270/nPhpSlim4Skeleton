# 門市據點模組規劃驅動文件

## 功能目標
- 維護各城市門市資訊（電話、地址、座標、地圖與訂餐連結）。
- 前台可依城市或關鍵字搜尋門市資訊。

## 使用者情境
- 營運人員新增或更新門市資料、調整營業狀態。
- 前台顯示城市列表、門市資訊、Google Maps 與線上點餐按鈕。

## 資料結構
- 城市分組 (t.7～t.9)。
- 每筆門市詳情：名稱、電話、地址、地圖連結、點餐連結（t.7-1～t.9-5）。
- 英雄區與表單內容（可選，若保留需同時管理）。

## 後台需求
- 城市 CRUD、排序、啟用。
- 門市資料管理：電話、地址、座標、備註、營業狀態（open/pause/closed）。
- 搜尋與篩選（依城市、關鍵字、狀態）。
- 若保留表單區：欄位設定、提交通知、資料匯出。

## 前端與 API
- `GET /api/front/locations/cities`：回傳城市與門市數量。
- `GET /api/front/locations?city=xxx`：回傳指定城市門市。
- `GET /api/front/locations/store/{id}`：單一門市資訊。
- Cache：城市列表可快取；門市更新時清除。

## 依賴與整合
- 外部連結設定（Google Maps、yoyvip 訂餐）。
- 表單模組（若保留）。
- 權限控管：僅營運相關角色可編輯。

## 風險與備註
- 地址需轉換座標，可透過 Geocoding API 預處理。
- 點餐連結若變動頻繁，需提供批次更新工具。
- 表單若啟用，需防止垃圾訊息並設通知流程。
