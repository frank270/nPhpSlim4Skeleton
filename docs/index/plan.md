# 首頁內容模組規劃驅動文件

## 功能目標
- 統一管理首頁英雄區、品牌標語、使命願景、CTA 連結與導流資訊。
- 與內頁共享品牌敘事資產，降低重複維護成本。

## 使用者情境
- 行銷人員調整首頁文案與圖片，立即反映於前台。
- 活動期間快速更新 CTA 連結與主視覺，並可回溯版本。

## 資料來源與結構
- 品牌標語：主、副標、補充標語 (t.1～t.6-3)。
- 導覽映射：About、Menu、News… 等導流文字 (t.09～t.14)。
- 敘事文案：使命、願景、長文敘事 (t.7、t.8、t.15)。
- 圖片資源：p.1～p.8（由媒體資產模組提供）。
- 外部連結：n.1 等設定（由外部連結模組提供）。

## 後台需求
- 後台可編輯欄位（多語、排序、草稿／發布狀態）。
- 圖片／連結選擇器需與媒體、外部連結模組整合。
- 支援版本歷程、草稿預覽與快速回滾。

## 前端與 API 介面
- `GET /api/front/home`：回傳 hero、narrative、cta 等資料物件。
- `GET /api/front/home/media`：提供圖片陣列（含尺寸、替代文字）。
- 快取策略：建議 12 小時自動刷新，並提供後台手動清除。

## 依賴與整合
- 媒體資產管理（圖片）。
- 外部連結設定（CTA、導流）。
- 品牌敘事模組（與 About 共享內容）。

## 風險與備註
- 長文需支援 Markdown／Rich Text，避免輸入安全問題。
- 需防止主要 CTA 被誤刪或導向錯誤網址。
- Hero 圖片與文本需設定 RWD 與無障礙（替代文字）。
