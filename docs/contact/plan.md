# 聯絡我們模組規劃驅動文件

## 功能目標
- 管理聯絡資訊（地址、Email、電話）與客服留言表單。
- 提供地圖嵌入、通知與案件追蹤機制。

## 使用者情境
- 客服更新聯絡資訊、調整客服電話或地址。
- 前台訪客提交意見或建議，系統通知客服並追蹤處理狀態。

## 資料結構
- 英雄區文案與圖片 (t.1-1～t.3, p.1)。
- 聯絡資訊區 (t.4～t.7)。
- 聯絡表單欄位：姓名、Email、電話、主題（餐點建議／服務回饋／其他）、訊息。
- 地圖嵌入資訊 (p.2)。

## 後台需求
- 聯絡資訊設定管理介面。
- 表單提交列表與狀態管理（新、處理中、已回覆）。
- 通知設定（Email、Slack 等）、回覆紀錄與備註。
- Spam 防護、匯出 CSV。

## 前端與 API
- `GET /api/front/contact`：回傳聯絡資訊與英雄區內容。
- `POST /api/front/contact/message`：表單提交。
- `GET /api/admin/contact/messages`：後台查詢留言。

## 依賴與整合
- 媒體資產（英雄圖、地圖圖片）：統一透過媒體資源庫（`public/upload/{Y}/{m}/uuid.ext`），支援 128 MB 上傳、進度條與圖片狀態/描述欄位。
- 外部連結設定（若需社群連結）。
- 通知系統。

## 風險與備註
- 表單需防範垃圾訊息（reCAPTCHA、Rate limit）。
- 必須符合個資法規，包含資料保存期限與匯出。
- 地圖嵌入應預留替代連結，以備 Google Maps 受限時使用。
