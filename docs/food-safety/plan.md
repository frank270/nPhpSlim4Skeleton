# 食品安全檢驗模組規劃驅動文件

## 功能目標
- 管理飲品、食材、肉品、其他等分類的檢驗報告。
- 提供檔案下載、分類瀏覽與搜尋功能。

## 使用者情境
- 品管人員上傳最新檢驗報告並設定有效日期。
- 前台依分類顯示報告列表，提供下載連結。

## 資料結構
- 分類 (t.9～t.12) 及對應圖示 (p.2～p.5)。
- 報告檔案：檔名、日期／批號 (t.13、t.14) 與 PDF 檔。
- 英雄區共用文案 (t.1～t.5) 與主圖 (p.1)。
- 外部連結 n.1（指向訂餐／門市資訊）。

## 後台需求
- 檔案上傳（PDF）、版本管理與到期提醒。
- 報告可標記「重點」顯示於列表頂端。
- 支援快速搜尋與分類篩選。

## 前端與 API
- `GET /api/front/food-safety?category=飲品`：回傳報告清單。
- `GET /api/front/food-safety/download/{id}`：產生簽章下載連結。
- Cache：分類列表可快取，下載需即時授權。

## 依賴與整合
- 媒體資產（分類圖示、英雄圖）：使用媒體資源庫（`public/upload/{Y}/{m}/uuid.ext`）統一管理，支援 128 MB 上傳、進度條、alt/caption 與狀態切換。
- 外部連結設定（n.1）。
- 權限控管：僅授權人員可上傳／下架報告。

## 風險與備註
- PDF 必須存於安全位置並記錄下載日志。
- 需設計到期提醒流程（Email／系統通知）。
- 可能需提供英文版報告，可擴充多語欄位。
