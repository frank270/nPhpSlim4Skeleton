# 關於我們模組規劃驅動文件

## 功能目標
- 管理品牌故事、數字成就、歷史時間軸等內容。
- 與首頁共享品牌敘事資料，減少重複維護。

## 使用者情境
- 品牌團隊更新里程碑事件與統計數據。
- 行銷定期更新品牌故事文案與圖片素材。

## 資料結構
- 品牌故事段落 (t.1)。
- 數字成就卡片 (t.2～t.4)。
- 歷史時間軸事件 (t.5～t.8)。
- 圖片資源 p.1～p.5 由媒體模組提供。

## 後台需求
- Story 區支援 Rich Text / Markdown。
- 成就卡可設定數值、單位、描述與排序。
- 時間軸事件支援年份、標題、描述、圖片、排序。
- 多語擴充、草稿／發布狀態、預覽。

## 前端與 API
- `GET /api/front/about`：回傳 story、metrics、timeline。
- 可提供 `include=shared` 參數回傳與首頁共享的內容。
- 快取建議 12 小時，提供手動清除。

## 依賴與整合
- 媒體資產管理（圖片對應）：使用媒體資源庫（`public/upload/{Y}/{m}/uuid.ext`）維護，支援 128 MB 上傳與後台進度條、alt/caption/狀態。
- 品牌敘事（共享資料組）。

## 風險與備註
- 敘事段落需控制字數與排版，可提供段落拆分。
- 時間軸排序需支援自動編號與年份檢查。
- 圖片需設定替代文字，符合無障礙需求。
