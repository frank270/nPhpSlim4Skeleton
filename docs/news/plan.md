# 最新消息 / 相簿模組規劃驅動文件

## 功能目標
- 管理活動、新品、展店、會員等類別的消息與相簿圖片。
- 支援首頁或其他頁面引用精選消息與圖片集。

## 使用者情境
- 行銷部上架新品活動、上傳圖片與摘要。
- 前台使用分類切換展示不同消息，同時提供更多消息列表。

## 資料結構
- 消息分類 (活動新品、展店消息、會員活動等)。
- 英雄區內容與圖片 (t.1～t.5, p.1)。
- 卡片圖文 (t.6～t.12, p.2～p.4)。
- 外部連結 n.1（門市／訂餐導向）。

## 後台需求
- 消息內容編輯器（標題、副標、摘要、內文、連結）。
- 圖片上傳與排序（多張）。
- 發布排程、置頂、分類與標籤管理。
- 多語與版本控管。

## 前端與 API
- `GET /api/front/news?category=...` 支援分頁與排序。
- `GET /api/front/news/latest` 回傳精選消息。
- `GET /api/front/news/{slug}`（若提供詳情頁）。
- Cache：分類列表可快取；內容更新需清除快取。

## 依賴與整合
- 媒體資產（資訊卡圖片）。
- 外部連結設定。
- 標籤管理模組。

## 風險與備註
- 需防止重複上架與內容交叉發布衝突。
- 圖片上傳需支援多尺寸（桌機／手機）。
- 若提供分享功能，需產出 Open Graph meta。
