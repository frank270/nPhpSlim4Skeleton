# FAQ 模組規劃驅動文件

## 功能目標
- 管理常見問題、分類與排序，供前台手風琴顯示。
- 提供多語與審核流程，確保內容一致且正確。

## 使用者情境
- 客服新增熱門問題或更新回答。
- 前台顯示 FAQ 列表，使用者可展開或搜尋。

## 資料結構
- FAQ 問題清單（含問題、回答）。
- FAQ 分類（若日後需要分組）。
- 英雄區副標與主標 (t.9)、圖片 p.1。

## 後台需求
- FAQ CRUD、分類管理、排序拖曳。
- 草稿／發布狀態、審核紀錄與版本存檔。
- 精選 FAQ 標記，可供首頁引用。

## 前端與 API
- `GET /api/front/faqs?category=...`：回傳 FAQ 列表。
- `GET /api/front/faqs/highlights`：精選 FAQ。
- 支援搜尋 API（關鍵字查詢）。
- Cache：FAQ 內容更新時清除快取。

## 依賴與整合
- 媒體資產管理（FAQ 圖片）：使用媒體資源庫（`public/upload/{Y}/{m}/uuid.ext`），128 MB 上傳限制與進度條，並可設定 alt/caption/狀態。
- 標籤系統（若需擴充）。

## 風險與備註
- FAQ 數量可能增加，需提供分頁或摺疊控制。
- 若支援多語，需加上 locale 欄位或翻譯表。
- 應考慮結構化資料（FAQPage schema）以提升 SEO。
