# 菜單模組規劃驅動文件

## 功能目標
- 管理菜單分類、商品資訊、價格與熱門標籤。
- 提供搜尋與篩選 API 支援前台模板呈現。

## 使用者情境
- 行銷新增期間限定商品並設定上下架。
- 門市主管調整價格，系統記錄價格歷程。
- 前台依分類、關鍵字、價格區間篩選商品。

## 資料結構
- 分類列表 (t.9～t.28)。
- 商品基本資料：名稱、描述、原價、優惠價、標籤。
- 圖片資源：p.1（英雄）、p.2～p.8（商品縮圖）。
- 外部連結：n.1 供線上訂餐導向。

## 後台需求
- ✅ 分類 CRUD、排序與啟用切換。
- ✅ 商品編輯：圖像 (ID)、價格、標籤 (字串)、Best Seller 設定。
- ✅ 狀態切換 (草稿/發布/封存)。
- ⏸️ 價格調整紀錄、通知（已移除）。
- ⏸️ 批次匯入／匯出商品資料（待實作）。

## 依賴與整合
- 媒體資產（商品圖片）：透過媒體資源庫（`public/upload/{Y}/{m}/uuid.ext`）管理，支援 128 MB 上傳、進度條、alt/caption 與狀態切換。
- 外部連結設定（訂餐連結）。
- 標籤管理模組（Popular Tags）。

## 風險與備註
- 價格需注意幣別與稅金顯示。
- 搜尋需防止 SQL Injection，並考慮全文索引。
- 標籤與分類需提供後台排序與多選功能。
