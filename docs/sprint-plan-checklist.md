# Sprint 進度檢查清單

> 搭配 `sprint-plan.md` 使用，於每個 Sprint 開始前確認準備事項，結束時檢查完工狀態。

## 通用檢查項目
- [ ] 需求與範圍確認，與利害關係人達成共識。
- [ ] 資料庫遷移腳本評估與備援方案確認。
- [ ] 測試計畫（單元測試、整合測試、前端 E2E）已排程。
- [ ] API 文件更新完成並同步給前端／第三方。
- [ ] 安全性與隱私需求評估（如上傳檔案、表單）。

---

## Sprint 1：共用內容基礎
### 起 Sprint 前
- [ ] 媒體資源庫儲存策略（S3、本地、CDN）確認。
- [ ] 品牌敘事資料來源與轉換需求明確。
- [ ] API 共用中介層、回應格式討論完成。

### Sprint 結束檢查
- [ ] 媒體上傳、檔案權限與刪除流程測試通過。
- [ ] 外部連結設定可在後台維護並套用至首頁/內頁。
- [ ] 品牌敘事資料可由後台更新並於前台顯示。
- [ ] API 測試、文件、快取策略完成。

---

## Sprint 2：菜單模組
### 起 Sprint 前
- [ ] 商品分類、標籤、價格調整需求確認。
- [ ] 舊資料匯入（若有）評估完成。

### Sprint 結束檢查
- [ ] 菜單後台 CRUD 與批次匯入／匯出可用。
- [ ] 前台可透過 API 搜尋／篩選並顯示商品。
- [ ] 價格歷程紀錄、快取、錯誤處理測試完成。
- [ ] 文件與教學提供給內容管理者。

---

## Sprint 3：門市據點模組
### 起 Sprint 前
- [ ] 城市分組與門市欄位（座標、狀態）確認。
- [ ] Google Maps、點餐連結維護流程討論完成。

### Sprint 結束檢查
- [ ] 後台門市列表可搜尋、排序、切換狀態。
- [ ] 前台可依城市顯示門市與連結，地圖正常。
- [ ] 表單（若保留）提交流程與通知測試。
- [ ] 更新流程文件與操作手冊。

---

## Sprint 4：食品安全檢驗模組
### 起 Sprint 前
- [ ] 檢驗報告存放、命名與有效期限規範確認。
- [ ] 到期提醒與授權需求明確。

### Sprint 結束檢查
- [ ] 後台可上傳、分類、下架報告，並記錄版本。
- [ ] 前台分類瀏覽、搜尋、下載流程測試通過。
- [ ] 下載日志與權限控制驗證完成。
- [ ] 文件更新，含檔案命名與上傳教學。

---

## Sprint 5：最新消息 / 相簿模組
### 起 Sprint 前
- [ ] 消息分類、標籤、排程與分享需求確認。
- [ ] 圖片處理（裁切、尺寸）策略決定。

### Sprint 結束檢查
- [ ] 後台可建立消息、排程、置頂，並上傳圖像。
- [ ] 前台分類切換、卡片展示與分享功能可用。
- [ ] 精選消息快取與刷新流程測試完成。
- [ ] 行銷團隊已接受操作訓練。

---

## Sprint 6：加盟合作模組
### 起 Sprint 前
- [ ] 加盟流程文案、表單欄位、通知需求確認。
- [ ] 法務／個資合規注意事項討論。

### Sprint 結束檢查
- [ ] 後台可維護流程步驟、聯絡資訊與表單資料。
- [ ] 前台表單提交成功並觸發通知、分派流程。
- [ ] CSV 匯出、狀態追蹤、審核流程運作正常。
- [ ] 隱私權聲明、使用條款已更新。

---

## Sprint 7：聯絡我們模組
### 起 Sprint 前
- [ ] 聯絡資訊、多渠道通知需求確認。
- [ ] Spam 防護（Captcha、Rate limit）策略確定。

### Sprint 結束檢查
- [ ] 後台可維護聯絡資訊，留言可指派與追蹤。
- [ ] 前台表單驗證、成功訊息、地圖嵌入正常。
- [ ] 通知（Email/Slack）測試成功，Spam 測試通過。
- [ ] 資料匯出與權限控制文件完成。

---

## Sprint 8：FAQ 模組
### 起 Sprint 前
- [ ] FAQ 結構、分類策略與多語需求確認。
- [ ] SEO 結構化資料需求（FAQPage schema）確認。

### Sprint 結束檢查
- [ ] 後台可 CRUD、排序、審核 FAQ，支援多語（若需）。
- [ ] 前台手風琴、搜尋、RWD 測試通過。
- [ ] SEO schema 與 Analytics 事件設定完成。
- [ ] FAQ 運維流程文件移交客服。

---

## Sprint 回顧與跨 Sprint 項目
- [ ] Sprint Retro 記錄：成就、阻礙、改善行動。
- [ ] 技術負債清單更新與追蹤。
- [ ] 多語、分析、效能優化等長期議題在看板上維護。
- [ ] 對應的文件（API、操作手冊）皆已同步更新。
