# Sprint 規劃總覽

> 依據後台模組優先順序，將主要開發工作拆分為 8 個 Sprint（假設每個 Sprint 為 2 週，可依實際情況調整）。

## 共同準備事項
- 建立媒體資產、外部連結、品牌敘事等共用資料表與後台介面。
- 定義 API 規範與回傳格式（JSON），並完成認證 / 權限檢查。
- 設定 CI/CD、資料庫遷移流程、快取策略、測試框架。

---

## Sprint 1：共用內容基礎
**目標**：完成後續模組所需的共用資產。

**參考文件**：
- `docs/index/plan.md`（品牌敘事模組）
- `docs/index/schema.md`
- `docs/index/todo.md`
- `docs/about/plan.md`（共用敘事延伸）
- `docs/cms/plan.md` / `docs/cms/todo.md` / `docs/cms/schema.md`

| 任務 | 說明 |
| --- | --- |
| 媒體資源庫 | 建立媒體上傳、分類、權限與 CDN/檔案儲存設定。 |

| 品牌敘事模組 | 建立首頁/關於共用的品牌敘事資料表與 API。 |
| API 基礎設施 | 設計統一回應格式、錯誤處理、中介層。 |

**完成標準**：共用模組資料結構、後台 CRUD、API 與文件上線。

## 後續建議
- Sprint 每結束需進行回顧與需求調整，調整下一期的範圍與優先度。
- 若資源足夠，可將 Sprint 5～8 視為 Phase 2，根據商業優先度排序。
- 針對多語、分析事件、性能優化等議題，可視專案進度穿插於各 Sprint。
