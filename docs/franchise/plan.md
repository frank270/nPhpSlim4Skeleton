# 加盟合作模組規劃驅動文件

## 功能目標
- 管理加盟流程步驟、聯絡資訊與加盟洽詢表單。
- 提供加盟表單提交後的通知與案件追蹤。

## 使用者情境
- 加盟顧問更新流程文案與輔導內容。
- 營運團隊接收新加盟申請並進行回覆。

## 資料結構
- 英雄區文案與圖片 (t.1～t.5, p.2)。
- 加盟流程 Step 01～03（含細項說明）。
- 聯絡資訊區 (t.6～t.8) 與 CTA 文案。
- 表單欄位：姓名、Email、電話、主題（加盟／了解／其他）、訊息內容。
- 圖片資源 p.2～p.5。

## 後台需求
- 流程步驟管理（名稱、描述、圖示、排序）。
- 聯絡資訊／CTA 管理（電話、Email、標語）。
- 表單提交列表、狀態（新、處理中、已結案）、備註與指派。
- 通知設定（Email、Slack 等）。

## 前端與 API
- `GET /api/front/franchise`：回傳流程、聯絡資訊、圖片。
- `POST /api/front/franchise/apply`：提交加盟表單。
- `GET /api/admin/franchise/applications`：後台查看申請列表。

## 依賴與整合
- 媒體資產管理（流程圖、插圖）。
- 外部連結設定（n.1）。
- 通知系統（Email / Slack / SMS）。

## 風險與備註
- 表單需防止垃圾訊息（Captcha、Rate limit）。
- 申請資料要符合個資法，需設定資料保存與匯出流程。
- 若未立即整合 CRM，需保留 API 以便後續串接。
